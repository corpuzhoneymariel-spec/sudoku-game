# Sudoku

A colorful, responsive Sudoku game that runs in your browser. Choose a difficulty, fill in the grid, and use the built-in tools to help solve each puzzle.

## Features

- Three difficulty levels: Easy, Medium, and Hard
- A countdown timer for each difficulty:
  - Easy: 10 minutes
  - Medium: 15 minutes
  - Hard: 20 minutes
- Up to five hints per puzzle
- Notes mode for marking possible numbers
- Check and erase tools
- Keyboard number entry and arrow-key navigation
- Restart the current puzzle or generate a new one

## How to play

1. Open the game and choose a difficulty.
2. Select an empty square, then enter a number using the number buttons or your keyboard.
3. Use Notes to jot down possibilities, Check to review your progress, or Hint to reveal an answer. Hints are limited to five per puzzle.
4. Fill every row, column, and 3×3 box with the numbers 1 through 9 before the countdown reaches zero.

## Run locally

No installation or build step is required. Open `index.html` in a modern web browser to play.
